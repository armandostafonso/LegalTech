Transparência

O que deves saber antes de utilizar.

Infraestrutura

O sítio é publicado no GitHub Pages. O alojamento e os recursos externos podem receber dados técnicos de acesso, conforme descrito na informação de privacidade.

Dados e documentos

Várias ferramentas tratam os dados introduzidos no navegador. Algumas páginas podem descarregar recursos externos. Confirma as condições específicas antes de utilizar informação confidencial.

Independência

A LegalTech Suite é um projeto independente. Não integra oficialmente o CITIUS, não é um serviço dos tribunais nem substitui os canais processuais autorizados.

Segurança e rigor

Os testes automáticos verificam comportamentos técnicos, mas não constituem uma auditoria de segurança, uma certificação RGPD ou uma validação jurídica integral.

Antes de inserir dados pessoais reais, confirma as políticas e autorizações da tua organização e consulta a informação completa de privacidade e limites.
